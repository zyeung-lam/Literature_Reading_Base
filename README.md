# Literature Reading Base

## 中文说明

### 作用与目的

`Literature_Reading_Base` 是一个公开、可持续积累的文献导读知识库，用于集中保存 Codex 按统一规范生成的中文 Markdown 文献导读。它的目标是让用户、不同设备上的 Codex，以及其他具备网页或 GitHub 读取能力的 agent，能够随时检索、阅读、引用和继续扩展这些导读。

除本说明文件外，仓库中的每个 Markdown 文件对应一篇论文，统一命名为：

```text
YYYY Exact English Paper Title.md
```

每篇导读应覆盖文献信息、核心问题、机制与方法、关键公式、实验结果、工程代价、创新点、局限、复现路线、推荐阅读顺序、组会问题、关键词和导读结论。写作时必须区分论文直接报告的事实、作者主张、图表估读和导读者评价。

### 供 Codex 或其他 agent 使用

标准生成流程由 [Literature_Reading_Guide_Skill](https://github.com/zyeung-lam/Literature_Reading_Guide_Skill) 定义。安装后可调用：

```text
$literature-reading-guide 阅读这篇论文，生成标准中文 Markdown 导读并保存到 Literature_Reading_Base。
```

执行顺序为：阅读全文与补充材料 → 核对权威元数据和来源 → 按固定结构撰写 → 运行格式校验 → 以规定文件名保存 → 仅提交该导读文件并推送到本仓库。

只读使用者或 agent 无需安装技能，也可以直接浏览本仓库、通过 GitHub 搜索论文标题或关键词，或读取对应 Markdown 文件。向仓库写入内容需要仓库所有者授权及 GitHub 写入权限。

本仓库仅保存这份双语 README 和最终版文献导读 Markdown；不存放脚本、模板、软件项目或无关笔记。

## English

### Purpose

`Literature_Reading_Base` is a public, continuously growing knowledge base for Chinese Markdown literature-reading guides generated by Codex under a consistent specification. Its purpose is to let the user, Codex on different devices, and other agents with web or GitHub access retrieve, read, cite, and extend the collection at any time.

Except for this README, each Markdown file represents one academic paper and follows this filename convention:

```text
YYYY Exact English Paper Title.md
```

Each guide should cover bibliographic information, the central problem, mechanism and method, key equations, experimental evidence, engineering costs, contributions, limitations, a reproduction roadmap, recommended reading order, discussion questions, terminology, and a final reading conclusion. Reported facts, author claims, plot-based estimates, and the guide writer's evaluation must remain clearly distinguishable.

### For Codex and other agents

The standard generation workflow is defined by [Literature_Reading_Guide_Skill](https://github.com/zyeung-lam/Literature_Reading_Guide_Skill). After installation, invoke it with:

```text
$literature-reading-guide Read this paper, create the standard Chinese Markdown guide, and save it to Literature_Reading_Base.
```

The workflow is: read the full paper and relevant supplements → verify authoritative metadata and sources → write the fixed guide structure → run the format validator → save with the required filename → commit only that guide file and push it to this repository.

Read-only users and agents do not need to install the skill. They can browse this repository, search GitHub by paper title or keyword, or retrieve the corresponding Markdown file directly. Writing to the repository requires the owner's authorization and GitHub write access.

This repository stores only this bilingual README and finalized literature-guide Markdown files. It does not contain scripts, templates, software projects, or unrelated notes.
